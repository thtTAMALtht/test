## ✅ Q&A

#### 1) What is the difference between var, let, and const?

- **`var`**: We can define it again and change the value. Function-scoped.
- **`let`**: We can't define it again, but we can change the value. Block-scoped.
- **`const`**: We can't define it again or change the value. Block-scoped.


#### 2) What is the difference between map(), forEach(), and filter()?

- **`map()`**: We run a function on each item and get back a new array.
- **`forEach()`**: We run a function on each item, but it doesn’t return anything.
- **`filter()`**: We get a new array with the items we want.


#### 3) What are arrow functions in ES6?

- **Arrow functions** are shorter way to write functions in JavaScript(ES6).
- They use the `=>` (arrow) syntax.
- If the function has only one expression,it returns the result automatically(no need for `return`).
- Arrow functions make code cleaner and easier to read.


#### 4) How does destructuring assignment work in ES6?

- **Destructuring** helps us take out values from arrays or objects.
- It assigns values directly to variables.

#### 5) Explain template literals in ES6. How are they different from string concatenation?

- **Template literals** use backticks `` ` `` instead of quotes `'` or `"`.
- Template literals can create multi-line strings without using `\n`.
- String concatenation uses the `+` operator to join strings and variables.
- But template literals use backticks `` ` `` and `${}` to insert variables directly inside strings.
